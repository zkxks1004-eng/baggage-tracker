✓

받을 수 있는 데이터

항목은 오지만 항공사마다 빠지는 곳 있음 (눌러서 확인)

  • 위탁 수하물 허용량개수·무게·크기 · 운임 브랜드·클래스별
    무엇
    운임 1개마다 무료 위탁 수하물 개수·무게·크기. 같은 편이라도 브랜드·예약 클래스에 따라 값이 달라질 수 있음 (예: EK325 Saver 25kg · Flex 30kg · Flex Plus 35kg)
    예시
    KE701 인천→나리타 Economy Saver(L)
    1P (UPTO50LB/23KG AND UPTO62LI/158LCM) 운임포함
    → 1개 · 23kg · 세 변 합 158cm
    읽는 법
    개수제: 전체 칸(1P·2P·3P)에 무료 개수, 가방 칸에 1개 기준 무게·크기
    무게제: 전체 칸에 총 무게(25K·30K 등)만 옴
    어디서
    Offer 응답 (GetOfferRequest → GetOfferResponse)
    빠지는 곳
    크기가 안 오는 곳: 무게제 항공사(7C·SQ·UL 등)와 ET·LA·SK·YP
    무게·크기 없이 개수만 오는 조회: TG·UA 유아
    무료 0인데 추가 요금이 비어 오는 조회: LA Basic, NZ·VJ 유아, ZE 이벤트 운임, 무게제 EY Basic·OD Super Saver·TW 이벤트·TK 유아(0kg)
    우리와 다른 값
    TG Standard(K): AirPlus 2개, 공홈·우리 1개 → AirPlus가 틀림
    LO 비즈니스: AirPlus 개당 23kg, 공홈·우리 32kg → AirPlus가 틀림
    SC 정상 운임(Y): AirPlus 2개, 공홈(중국어판)·우리 1개
    UL 인천→콜롬보: AirPlus 45kg, 공홈·우리 30kg (아마데우스도 45kg이라 한국 노선 운임 예외일 수 있음)
  • 기내 수하물 허용량개수·무게·크기
    무엇
    기내 반입 가방 개수·무게·크기
    예시
    KE701 Economy: 1P (UPTO22LB/10KG AND UPTO45LI/115LCM)
    → 1개 · 10kg · 115cm
    KE701 First: 2P (UPTO40LB/18KG AND UPTO45LI/115LCM)
    → 2개 · 18kg · 115cm (공홈·우리는 2개 합계 18kg)
    어디서
    Offer 응답
    빠지는 곳
    무게가 안 오는 곳: AA·AC·AY·DL·OZ·UA, SQ 비즈니스
    크기가 안 오는 곳: AC·OZ·UA, SQ 비즈니스, 무게만 오는 항공사(AI·KC·TG 등)
  • 유아 허용량유아 값은 따로 옴 · 소아는 성인과 같은 값
    무엇
    승객 유형을 유아로 바꿔 조회하면 유아 허용량이 따로 나옴
    예시
    SQ601 인천→싱가포르 Economy Flexi(B) 유아: 위탁 10Kilograms 운임포함
    (같은 운임 성인은 30kg)
    참고
    허용량은 유아 기준으로 오지만 운임 금액은 대부분 성인 기준 (EY·MH·NZ·TG만 유아 운임)
    소아
    소아로 조회하면 성인과 같은 값으로 옴. MH만 다른데, 소아 규정이 아니라 다른 브랜드 운임이 붙은 것 → 소아 전용 규정은 이 응답으로 알 수 없음
    빠지는 곳
    유아 값이 성인과 똑같이 오는 곳: AC·AY·CA·LH·LO — AY·CA·LH·LO는 공홈도 같음, AC는 공홈 본문에 없어 확인 필요
    NH·JL은 유아 1개(성인 2개)로 따로 오고 공홈과 같음
    무게·크기 없이 개수만 오는 곳: TG·UA
    유아 무료 위탁 0개로 오는 곳: KC·NZ·VJ(우리 데이터와 같음), TK(0kg — 우리 데이터와 다름)
    유아 기내는 KE·SQ·LH 등에서 무료 없음(별도)으로 옴
  • 노선·환승 여정별 허용량같은 항공사라도 노선마다 다른 값
    무엇
    구간을 바꾸거나 환승 여정(2구간)으로 조회하면 그 여정의 값이 나옴
    예시
    EK 두바이→뉴욕: 2개 · 개당 23kg · 150cm (개수제)
    EK 인천→두바이: 무게제
    AF 파리→뉴욕 Light: 첫 위탁부터 약 105,231 KRW 별도
    참고
    환승은 실제 출발 시각을 넣어야 함 (00:00이면 날짜 순서 오류). 이번엔 두 구간 클래스를 같게 맞춰서 받음 · 다른 항공사 연결은 조회 안 해 봄
    빠지는 곳
    일부 노선은 운임 없음으로 옴 (예: OZ 인천→LA)
  • 운임 브랜드 · 예약 클래스 · 운임 코드클래스·운임 코드는 다 옴 · 브랜드명은 빠지는 곳 있음
    무엇
    그 운임이 어떤 브랜드(Saver·Flex 등)인지, 예약 클래스(RBD)·운임 코드·브랜드 단계
    예시
    KE701 L → Economy Saver · 단계 1 · 운임코드 LHEV0SEN
    KE701 Y → Economy Flex · 단계 3 · YOW
    KE701 F → First · 단계 9 · FOW
    어디서
    Offer 응답 (검색 v1 BrandNameTitle에도 일부 있음)
    빠지는 곳
    브랜드명·단계가 비어서 오는 곳: 3U·CZ·ET·SC, KE 선원·VN 학생 조회(다른 특수운임은 브랜드 옴), HU 비즈니스(C) — 클래스·운임 코드는 옴
    이코노미 클래스를 바꿔도 브랜드가 한 값인 곳: 7C(FLYBAG)·EY(Y도 Economy Basic)·KC·LH·OD(Y도 Super Saver)·WY 등
  • 브랜드 혜택포함/유료/불가 — 좌석 지정·기내식·마일리지 적립 등
    무엇
    그 브랜드에 무엇이 포함·유료·불가인지
    예시
    KE Economy Saver
    포함: 기내·위탁 수하물, 기내식
    유료: 변경, 환불
    불가: 라운지, 우선 탑승·체크인, 좌석 지정
    어디서
    Offer 응답 (브랜드 속성)
    빠지는 곳
    3U·CZ·ET·SC와 브랜드 없이 오는 조회(KE 선원·VN 학생·HU 비즈니스): 혜택도 없음
    "불가"가 늘 비어 오는 곳: BR·FM·HU·JL·MU·PR / 대부분 비어 오는 곳: AA·AM·GA·LO·NH·SQ
    "유료"가 비어 오는 곳: OM · "포함"이 비어 오는 운임: OD Super Saver
    위탁 수하물 항목이 아예 안 나오는 곳: GA·OM·VJ
    안 맞는 값
    변경·환불 표시가 수수료 칸과 안 맞는 경우 있음
    QF·UL Economy Flex: 환불 포함인데 취소 수수료 있음
    BR·OD: 변경 포함인데 100%
    GA·KE·PR·ZE: 환불 유료인데 취소 0 (0은 무료인지 빈 값인지 모름)
    → 어느 쪽이 맞는지는 공홈 확인 필요
  • 취소·변경 수수료1장당 금액 또는 % · 언제나·출발 전·후·노쇼
    무엇
    취소·변경 1장당 수수료(금액 또는 %)와 적용 시점
    예시
    KE Economy Saver(L): 변경 100,000 KRW · 취소(출발 전) 220,000 KRW
    KE Economy Flex(Y): 변경 0 · 취소 0
    같은 Flex라도 B 클래스는 변경 40,000 · 취소 80,000 KRW
    참고
    수수료는 브랜드가 아니라 운임 코드마다 다름
    "불가"는 따로 표시 없음. 100%로 오는 운임이 많지만, 제약 문구는 환불·변경 불가인데 금액이나 0으로 오는 운임도 있음 (AM·EY·VJ·8M)
    출발 전·후·노쇼 구분은 KE·AF·LH 등 일부만, 7C·SQ·QR 등은 "언제나" 한 값
    0은 통화 없이 와서 무료인지 값이 없는 건지 구분 안 됨
    "출발 며칠 전" 같은 기간 단계는 없음
    빠지는 곳
    변경 칸이 비어 오는 곳: CA·ZH(매번), KC 비즈니스(C)·LA 프리미엄(W) (취소는 다 옴)
  • 총운임 · 세금 · 유류할증료
    무엇
    기본운임 + 세금(코드별) + 원화 총액. 유류할증료는 따로 칸이 없고 세금 속 YQ·YR 코드로 옴
    해외 출발 운임만 원래 통화 금액이 같이 오고, 환율 칸은 없음 (운임 계산식의 ROE만)
    예시
    KE701 Economy Flex(Y) 총 458,300 KRW
    KE701 Economy Saver(L) 총 353,800 KRW
    참고
    하루 뒤 같은 조회에서 원화 금액이 조금 바뀐 곳 있음 (AF·EK·LH·QR·TK·UA: 유류할증료·외화 운임 환산). KE·7C·SQ 등은 그대로
    실제 판매가와는 7C 한 편만 대조(몇백 원 차), 다른 항공사는 대조 안 함 · 잔여석 미반영(②)
    빠지는 곳
    총액·기본운임·세금은 운임이 나오면 다 옴 · 유류할증료(YQ·YR)는 KC·NZ 응답에 한 번도 없음
  • 항공사 수하물 안내 링크항공사 코드만 바뀌는 고정 링크
    무엇
    수하물 칸에 붙어 오는 트래블포트 주소. 항공사 코드만 바뀌고 운임·노선마다 같음. 열면 트래블포트에 등록된 항공사 페이지로 넘어감
    예시
    http://VIEWTRIP.TRAVELPORT.COM/BAGGAGEPOLICY/KE
    → 대한항공 공홈 무료 수하물 페이지 (TG는 타이항공 수하물 페이지)
    어디서
    Offer 응답 (수하물 칸의 url)
    빠지는 곳
    연결이 이상한 곳: VJ·ZH는 "등록 없음" 화면, HU는 공홈이 아닌 여행 사이트, SC는 공홈 첫 화면
    Offer가 안 나오는 5J·BX·QV·RS·HA는 링크도 없음
    참고
    링크 너머 공홈 내용(특수수하물, 무게·크기 초과 요금 등)은 응답에 없음
  • 기내 서비스기내식·음료·엔터·USB·와이파이·좌석 배열·기종
    무엇
    편·좌석 등급별 기내 서비스
    예시
    EK 인천→두바이 이코노미
    기내식 제공 · 주류·음료 제공 · 좌석스크린 VOD·라이브TV
    기본 웹 브라우징(유료) · 전원 공급 장치·USB 포트
    좌석배열 3-4-3 · 777(대형기종) · 좌석 간격 81cm
    어디서
    검색 v2 (한국어 문장) · Offer 응답 (영문, 서버가 편을 찾아 시각을 채워 준 편만)
    빠지는 곳
    검색 v2에서 비어 오는 곳: KE·JL·HX·TW·UL·VJ·SC·3U (KE·JL은 다른 노선 편에서만 Offer로 옴, 예 KE901·JL6)
    조회 불가: 5J·BX·FM·RS(FM은 Offer에서 옴), QV·HA
    서비스가 오는 항공사도 편에 따라 빔 (LO·QF·NX·OM 등)
    검색 v2에선 와이파이·엔터·USB 칸이 비는 곳 많음 (와이파이 OZ·CX·TG, 엔터·USB 7C·ZE·8M 등). Offer에선 같은 편이 "No Wi-Fi"·"No entertainment"로 와서, 빈 칸은 "서비스 없음"일 가능성이 큼
  • 좌석 수치 · 정식 기종명좌석 간격·폭·기울기
    무엇
    항공사·기종·좌석 등급별 기종명과 좌석 간격·폭·기울기
    예시
    SQ A350 이코노미: Airbus Industrie A350-900
    간격 81.28 · 폭 45.72 · 기울기 15.24 (cm)
    어디서
    AirEquipment (문서에 없던 API)
    빠지는 곳
    시험한 기종 코드로 빈 값만 온 곳: AI·ET·HU·MF·MU·NZ·OM·SK·SV·VN·ZH (다른 코드면 나올 수 있음)
    기종을 몰라 조회 못 한 곳: 3U·HX·JL·SC·TW·UL·VJ 등
    기종명만 오고 좌석 수치가 없는 곳: 8M·CA·CZ·LA·LH
    기울기는 절반 정도만 옴
    틀린 값
    단위가 섞이거나 이상한 값: QR 비즈니스 inch 표시, OD 이코노미 간격 32cm(인치 값으로 보임), YP 기울기 174°
    검색 v2와 값이 다른 곳: SQ 787 이코노미 76cm vs 81cm
    777 계열은 "Boeing 777" 하나로 뭉쳐 옴
  • 비행 거리 · 터미널출발·도착 터미널
    무엇
    구간 비행 거리(마일, 응답에 단위 없음 · 도시 간 거리로 보임), 출발·도착 터미널
    예시
    SQ 인천→싱가포르: 거리 2884 · 출발 터미널 1 · 도착 터미널 빈 값
    어디서
    검색 v2 · Offer 응답
    빠지는 곳
    거리: 5J·BX·HA·QV·RS 없음
    터미널: KE·JL·HX·TW·UL·VJ 등은 출발·도착 둘 다 없음, 도착은 SQ·QR·TK 등도 없음. Offer도 같은 편은 같음 (KE·JL은 다른 노선 편에서만 옴, 예 KE901·JL6)
    번호 대신 "I"로 오는 곳 있음 (DL·UA 등)
△

있긴 한데 부족한 것

값은 오지만 그대로 믿거나 일반화하기 어려운 것

  • 안 나오는 항공사5J·BX·QV·RS·HA
    무엇
    조회해도 수하물·운임이 안 나오는 항공사
    예시
    5J·BX·QV·RS: CARRIER EXISTS BUT IS NON PARTICIPANT (미참여)
    HA: REQUESTED CABIN HAS NO AVAILABLE FARES (운임 없음 · 인천→호놀룰루 한 편만 시험)
    그래서
    5J·QV는 우리 GDS로 확인 가능 · BX·RS·HA는 GDS에도 안 나와 공홈으로만 확인
  • 규칙이 아니라 조회 1건의 답어느 노선·조건에 적용되는지는 없음
    무엇
    응답은 "이 편·이 날짜·이 클래스·이 승객"의 결과 하나뿐
    예시
    KE701 인천→나리타 11/20 Saver → 1개 23kg
    → 같은 값이 KE 일본 노선 전체에 해당하는지는 알 수 없음
    MH38 같은 Y 클래스도 성인은 Basic(25kg), 소아는 Flex(35kg)로 옴
    그래서
    규칙으로 쓰려면 노선·조건을 바꿔 여러 번 조회해야 함 · 클래스만으로 브랜드가 정해지지 않음
  • 좌석 등급별 예약 클래스 목록대표 클래스 몇 개만 옴
    무엇
    항공사 + 좌석 등급을 넣으면 그 등급의 예약 클래스가 오는데, 대부분 몇 개만 오고 할인 클래스는 빠짐
    예시
    KE 이코노미(Y) → Y, M, B
    (Offer로 운임이 나온 L(Saver)·S(Standard)는 목록에 없음)
    어디서
    AirlineSeatGradeBookingClass (문서에 없던 API)
    빠지는 곳
    모든 등급이 빈 값: 5J·BX (같은 미참여인 QV·RS와 운임 없는 HA는 목록이 옴)
    그래서
    클래스→등급 대응표로 그대로 쓰면 빠지는 클래스가 많음
  • 추가 위탁 요금근사치 · 둘째 가방까지만 · 금액 없는 항공사 많음
    무엇
    무료 개수를 넘는 가방 요금. 요금이 올 때는 무료 1개면 둘째 가방, 무료가 없으면 첫째·둘째 가방(AF·KL·LH Light 등) 요금이 옴. 셋째 가방부터는 없음
    전부 원화 근사치(약)로 옴 · 인천 출발도 AF·CA·LH·TK는 하루 사이 100원 단위로 바뀌어 외화 환산값으로 보임 (KE는 고정)
    예시
    KE701 Economy 두 번째 가방: 1P 23kg · 약 70,000 KRW 별도
    AF 인천→파리 Standard 두 번째 가방: 약 188,000 KRW 별도
    빠지는 곳
    금액이 안 오는 곳: 무료 2개 이상·무게제 운임(EK·QR·SQ·QF·GA 등), 요금 칸이 "BAGGAGE CHARGES DATA NOT AVAILABLE"로 오는 곳(LA·NX·YP, ZE 이벤트, NZ·VJ 유아 등)
    무게·크기 대신 FIRST BAG·PRE PAID BAGGAGE 글자만 오는 곳: 3U·KC·VN·TG·OM·SV
    그래서
    무게·크기 초과 요금, 셋째 가방부터, 사전 구매 할인은 없음 → ③ 초과요금 전체
  • 상위 클래스 기내 값일반석 값으로 나오는 경우 있음
    무엇
    비즈니스·프리미엄인데 기내 무게가 일반석 값 그대로 오는 경우
    예시
    ZH 비즈니스 기내: AirPlus 2개 × 5kg
    공홈: 2개 × 8kg
    KC 비즈니스·LO 프리미엄도 일반석과 같은 값으로 옴
    그래서
    정답이 아니라 검수용으로 쓰는 게 안전
  • 최저가(Lite) 운임항공사에 따라 안 나옴
    무엇
    일부 항공사는 가장 싼 브랜드 클래스가 "운임 없음"으로 옴 (SQ·QR·VN·DL·AA). EY Basic, AF·KL·LH Light, UA Basic Economy 등은 나옴
    예시
    SQ601 이코노미 Lite(V) · 비즈니스 Lite(D) → 운임 없음
    (같은 편 Value·Standard·Flexi는 나옴)
    그래서
    최저가 운임의 수하물·가격은 AirPlus로 못 볼 때가 있어 공홈으로 보완 (예: SQ Lite 25kg)
  • 학생·선원·근로자 운임대부분 성인 운임으로 대체됨
    무엇
    특수 승객 유형으로 요청해도 대부분 성인(ADT) 운임으로 바꿔서 줌. 특수운임이 실제 붙은 곳은 SQ·8M·KE 선원, UL·HU·VN 학생, NZ 근로자뿐
    예시
    7C 학생(STU) 요청 → 적용 승객 ADT, 운임·수하물 성인과 같음
    SQ601 선원(SEA) → 선원 운임, 위탁 40kg (성인 30kg)
    참고
    운임은 성인이어도 수하물은 다르게 오는 곳 있음: CA·SC 학생과 FM 학생·선원·근로자 위탁 2개(성인 1개), CZ 학생 3개(성인 2개), QF 선원 40kg, ZE 근로자 23kg
    그래서
    특수운임 조건은 따로 모아야 함(③) · 군인은 Offer로 조회 안 해 봄 (검색 API는 군인을 넣어도 성인과 같은 값)
  • 조회 기준 대리점을 우리가 정하지 않음우리 조건으로 보면 다를 수 있음
    무엇
    우리가 PCC를 넣지 않았는데 응답의 발권 대리점이 전부 31I3으로 찍힘 → AirPlus 서버가 정한 대리점 기준 (트래블포트 쪽으로 보이나 미확인)
    그래서
    우리 PCC(있다면)로 조회하면 운임·브랜드가 다를 수 있음(시험 안 해 봄)
  • 잔여석반영 안 됨 — 매진 클래스도 가격이 나옴
    무엇
    조회할 때 좌석 재고 확인이 꺼져 있음
    예시
    reCheckInventoryInd: false
    그래서
    "지금 살 수 있는 운임"으로 쓰면 안 됨
  • 반입 제한(Embargo)"있음"과 링크만
    무엇
    AA·NZ·MF는 조회마다, DL·QF는 일부 노선(뉴욕→파리, 시드니→LA)에서만 반입 제한 항목이 오고 내용은 비어 있음
    예시
    AA: baggageType "BaggageEmbargo"
    url: http://VIEWTRIP.TRAVELPORT.COM/BAGGAGEPOLICY/AA
    (일반 수하물 안내와 같은 링크, 제한 내용 없음)
    그래서
    제한 내용은 따로 모아야 함(③)
  • 검색 API 브랜드명오는 항공사가 절반이 안 되고, 일부는 클래스와 상관없이 같은 값
    무엇
    검색 v1 브랜드명은 일부 항공사만 오고, CX·HX·LH·NH·SC·SV·TK는 클래스를 바꿔도 같은 값 (v2엔 브랜드명 없음)
    예시
    CX 이코노미·프리미엄·비즈니스·퍼스트 전부 "ECONOMY FLEX"
    NH 전 클래스 "INT REDEMPTION AWARD" (마일리지 항공권 이름)
    OZ는 "Economy - 359"처럼 좌석 등급 + 기종 코드
    그래서
    브랜드 매핑엔 Offer 쪽 브랜드명이 나음 (단 SC는 Offer도 비어 있고, 7C 이코노미는 둘 다 FLYBAG)
  • 기내·외부·기내식 사진일부 항공사만
    무엇
    기내·기체 외부·기내식 사진 주소
    어디서
    검색 v2 (기종 코드 넣을 때) · AirEquipment · InflightMeal
    빠지는 곳
    기내·외부 사진은 절반 정도 항공사만 옴 (KE·BR·CA·CZ 등 없음, CX·CI는 외부 사진만)
    기내식 사진도 KE·EK·OZ·JL 등 없음
    참고
    기내·외부 사진은 등록된 기종 코드를 넣어야 나옴 (SQ는 359는 나오고 789는 안 나옴) · 기내식 사진은 코드 없이도 옴 · 화면에 써도 되는지 미확인(아래 이용 조건)
  • 기준일응답에 없음 · 코로나 항목, 2020년에 올린 사진 섞임
    무엇
    검색 API 값(기내 서비스·사진·코로나 항목)은 언제 기준인지 날짜가 없음 (사진 주소의 등록 연월뿐). 코로나 시기 항목도 아직 나옴
    예시
    EK Covid19: MandatoryMask "Yes" · MiddleSeatBlocked "No" · HealthCert "Yes"
    그래서
    기내 서비스·사진 값은 화면에 쓰기 전 공홈으로 확인 필요 (③ URL 감시는 수하물 규정 페이지만 대상)
  • 가격 투명성 · 운임 규정 원문 APIPCC·여정 입력 형식이 없어 못 받음 · 미해결 과제
    무엇
    문서에 없던 API. 10/13 시험했지만 실제 응답은 못 받음
    예시
    GetPriceTransparency: "필수 입력 항목 PCC가 없습니다."
    임시 PCC를 넣으면 PlatingCarrier → Itinerary1 순서로 막힘
    여정 입력은 "^" 구분 20칸 이상(swagger 설명뿐)인데 칸마다 무엇을 넣는지 문서 없음
    GetAirPricing · GetFareRule: 위 응답의 키가 있어야 함
    받으면
    적립 마일·적립률 · 출발 전 기간별 취소·변경 수수료 · 구간별 규정
    열려면
    우리 PCC(또는 써도 되는 PCC) + 여정 형식 문서 → 트래블포트 확인 필요 (10/14 보류)
  • 빈 항목항공사 정보 · 좌석 배열 API · BrandedFare API
    무엇
    필드나 API는 있는데 값이 비거나 "결과 없음"으로 옴
    예시
    AirlineInfo · AirlineInfoLink · AirlineInfoImage: "" (문서상 준비 중)
    SeatArrangement API: {"ColDef": ""} (검색 v2의 좌석 배열 칸은 값이 옴)
    BrandedFare API: "조건에 맞는 Family 결과가 없습니다." (KE만, PCC 없이 시험)
    참고
    검색 v1은 미참여 항공사(QV)도 Success로 빈 값을 줌 → 성공 표시만 보고 데이터가 있다고 보면 안 됨
  • 이용 조건호출 한도·과금·사진 사용 범위 미확인
    무엇
    얼마나 불러도 되는지, 돈이 드는지, 사진을 화면에 써도 되는지 아직 모름
    참고
    지금은 개발 서버만 조회 · 운영 서버 호출은 Aggregator 몫
