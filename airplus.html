받을 수 있는 데이터

AirPlus 응답으로 바로 오는 것

  • 위탁 수하물 허용량개수·무게·크기 · 운임 브랜드·클래스별
    무엇
    운임 1개마다 무료 위탁 수하물 개수·무게·크기. 같은 편이라도 브랜드·예약 클래스가 바뀌면 값이 달라짐
    예시
    KE701 인천→나리타 Economy Saver(L)
    1P (UPTO50LB/23KG AND UPTO62LI/158LCM) 운임포함
    → 1개 · 23kg · 세 변 합 158cm
    어디서
    Offer 응답 (GetOfferRequest → GetOfferResponse)
  • 기내 수하물 허용량개수·무게·크기
    무엇
    기내 반입 가방 개수·무게·크기
    예시
    KE701 Economy: 1P (UPTO22LB/10KG AND UPTO45LI/115LCM)
    → 1개 · 10kg · 115cm
    KE701 First: 1개 · 18kg
    어디서
    Offer 응답
  • 추가 위탁 요금두 번째 가방 등
    무엇
    무료 허용량을 넘는 다음 가방의 요금
    예시
    KE701 Economy 두 번째 가방: 1P 23kg · 약 70,000 KRW 별도
    AF 인천→파리 Standard 두 번째 가방: 약 188,000 KRW 별도
    참고
    금액은 "약"(근사치)으로 오고 원화로 바뀌어 옴 → ②의 "추가 요금" 참고
  • 승객 유형별 허용량소아·유아
    무엇
    승객 유형을 소아·유아로 바꿔 조회하면 그 유형의 허용량이 나옴
    예시
    SQ601 인천→싱가포르 유아(INF): 위탁 10Kilograms 운임포함
    (같은 편 성인은 30kg)
    참고
    허용량은 유아 기준으로 오지만 운임 금액은 대부분 성인 기준
  • 노선·환승 여정별 허용량같은 항공사라도 노선마다 다른 값
    무엇
    구간을 바꾸거나 환승 여정(2구간)으로 조회하면 그 여정의 값이 나옴
    예시
    EK 두바이→뉴욕: 1P 23kg (개수제)
    EK 인천→두바이: 무게제
    AF 파리→뉴욕 Light: 첫 위탁부터 약 105,231 KRW 별도
    참고
    환승은 실제 출발 시각을 넣고, 두 구간을 같은 클래스로 보내야 나옴
  • 운임 브랜드 · 예약 클래스 · 운임 코드브랜드명·단계 포함
    무엇
    그 운임이 어떤 브랜드(Saver·Flex 등)인지, 예약 클래스(RBD)·운임 코드·브랜드 단계
    예시
    KE701 L → Economy Saver · 단계 1 · 운임코드 LHEV0SEN
    KE701 Y → Economy Flex · 단계 3 · YOW
    KE701 F → First · 단계 9 · FOW
    어디서
    Offer 응답 (검색 v1 BrandNameTitle에도 일부 있음)
  • 좌석 등급별 예약 클래스 목록이코노미·비즈니스 등 → 클래스
    무엇
    항공사 + 좌석 등급을 넣으면 그 등급에 속한 예약 클래스 목록
    예시
    KE 이코노미(Y) → Y, M, B
    KE 프리미엄(P) → W
    어디서
    AirlineSeatGradeBookingClass (문서에 없던 API)
  • 브랜드 혜택포함/유료/불가 — 좌석 지정·기내식·마일리지 적립 등
    무엇
    그 브랜드에 무엇이 포함·유료·불가인지
    예시
    KE Economy Saver
    포함: 기내·위탁 수하물, 기내식
    유료: 변경, 환불
    불가: 라운지, 우선 탑승·체크인, 좌석 지정
    어디서
    Offer 응답 (브랜드 속성)
  • 취소·변경 수수료언제나·출발 전·출발 후·노쇼
    무엇
    취소·변경 가능 여부와 1장당 수수료, 적용 시점
    예시
    KE Economy Saver: 변경 100,000 KRW · 취소 220,000 KRW
    KE Economy Flex: 변경 0 · 취소 0
    참고
    "출발 며칠 전" 같은 기간 단계는 없음
  • 총운임 · 세금 · 유류할증료
    무엇
    운임 + 세금(코드별) + 유류할증료, 원래 통화 운임과 환율
    예시
    KE701 Economy Flex 총 458,300 KRW
    KE701 Economy Saver 총 353,800 KRW
    참고
    금액대는 실제와 같지만 원 단위까지 맞지는 않음 · 잔여석 미반영(②)
  • 항공사 수하물 안내 링크
    무엇
    항공사별 수하물 정책 안내 페이지 주소
    예시
    http://VIEWTRIP.TRAVELPORT.COM/BAGGAGEPOLICY/KE
  • 기내 서비스기내식·음료·엔터·USB·와이파이·좌석 배열·기종
    무엇
    편·좌석 등급별 기내 서비스. 한국어 문장으로 옴
    예시
    EK 인천→두바이 이코노미
    기내식 제공 · 주류·음료 제공 · 좌석스크린 VOD·라이브TV
    기본 웹 브라우징(유료) · 전원 공급 장치·USB 포트
    좌석배열 3-4-3 · 777(대형기종) · 좌석 간격 81cm
    어디서
    검색 v2 (BrandedFareService/Search, version 2)
  • 좌석 수치 · 정식 기종명좌석 간격·폭·기울기
    무엇
    항공사·기종·좌석 등급별 정식 기종명과 좌석 수치(cm)
    예시
    SQ A350 이코노미: Airbus Industrie A350-900
    간격 81.28 · 폭 45.72 · 기울기 15.24 (cm)
    어디서
    AirEquipment (문서에 없던 API)
  • 사진 · 비행 거리 · 터미널기내·외부·기내식 사진
    무엇
    기내·기체 외부·기내식 사진 주소, 비행 거리, 출발·도착 터미널
    예시
    SQ 인천→싱가포르: 거리 2884 · 출발 터미널 1
    참고
    기내·외부 사진은 기종 코드를 넣어야 나옴
△

있긴 한데 부족한 것

값은 오지만 그대로 믿거나 일반화하기 어려운 것

  • 안 나오는 항공사5J·BX·QV·RS·HA
    무엇
    조회해도 수하물·운임이 안 나오는 항공사
    예시
    5J·BX·QV·RS: CARRIER EXISTS BUT IS NON PARTICIPANT (미참여)
    HA: REQUESTED CABIN HAS NO AVAILABLE FARES (운임 없음)
    그래서
    이 항공사들은 공홈·GDS로만 확인
  • 규칙이 아니라 조회 1건의 답어느 노선·조건에 적용되는지는 없음
    무엇
    응답은 "이 편·이 날짜·이 클래스·이 승객"의 결과 하나뿐
    예시
    KE701 인천→나리타 11/20 Saver → 1개 23kg
    → 같은 값이 KE 일본 노선 전체에 해당하는지는 알 수 없음
    그래서
    규칙으로 쓰려면 노선·조건을 바꿔 여러 번 조회해야 함
  • 상위 클래스 기내 값일반석 값으로 나오는 경우 있음
    무엇
    비즈니스·프리미엄인데 기내 무게가 일반석 값 그대로 오는 경우
    예시
    ZH 비즈니스 기내: AirPlus 2개 × 5kg
    공홈: 2개 × 8kg
    그래서
    정답이 아니라 검수용으로 쓰는 게 안전
  • 최저가(Lite) 운임잘 안 나옴
    무엇
    가장 싼 Lite 브랜드 클래스는 조회해도 운임 없음으로 오는 경우가 많음
    예시
    SQ 이코노미 Lite(V) · 프리미엄 Lite(R) · 비즈니스 Lite(D) → 운임 없음
    그래서
    무료 위탁이 없는 운임이 빠지기 쉬움
  • 학생·선원·근로자 운임대부분 성인 운임으로 대체됨
    무엇
    특수 승객 유형으로 요청해도 성인(ADT) 운임으로 바꿔서 줌
    예시
    요청 승객 STU(학생) → 적용 승객 ADT, 운임·수하물 성인과 같음
    그래서
    특수운임 조건은 따로 모아야 함(③)
  • 조회 기준이 트래블포트 쪽 대리점우리 조건으로 보면 다를 수 있음
    무엇
    응답의 발권 대리점이 우리 회사가 아니라 트래블포트 쪽 코드로 찍힘
    그래서
    우리 PCC로 조회하면 운임·브랜드가 다를 수 있음(시험 안 해 봄)
  • 잔여석반영 안 됨 — 매진 클래스도 가격이 나옴
    무엇
    조회할 때 좌석 재고 확인이 꺼져 있음
    예시
    reCheckInventoryInd: false
    그래서
    "지금 살 수 있는 운임"으로 쓰면 안 됨
  • 추가 요금근사치 · 추가 1개 요금만
    무엇
    추가 가방 요금은 근사치 표시가 붙고 원화로 환산돼 옴. 다음 1개 요금만 있음
    예시
    1P (23KG · 158CM) 약 70,000 KRW 별도
    그래서
    무게·크기 초과 요금, 사전 구매 할인은 없음 → ③ 초과요금 전체
  • 반입 제한(Embargo)"있음"과 링크만
    무엇
    노선·시기별 수하물 반입 제한이 있다는 표시만 오고 내용이 비어 있음
    예시
    AA: baggageType "BaggageEmbargo"
    url: VIEWTRIP.TRAVELPORT.COM/BAGGAGEPOLICY/AA (내용 없음)
    그래서
    제한 내용은 따로 모아야 함(③)
  • 검색 API 브랜드명클래스와 상관없이 기본값으로 나오는 항공사 많음
    무엇
    검색 v1의 브랜드명이 클래스를 바꿔도 같은 값
    예시
    CX 이코노미·프리미엄·비즈니스·퍼스트 전부 "ECONOMY FLEX"
    OZ는 "Economy - 359"처럼 좌석 등급 + 기종명
    그래서
    브랜드 매핑엔 Offer 쪽 브랜드명이 나음
  • 기준일응답에 없음 · 옛 데이터(코로나 항목·옛 사진) 섞임
    무엇
    값이 언제 기준인지 알려주는 날짜가 없음. 코로나 시기 항목도 아직 나옴
    예시
    EK Covid19: MandatoryMask "Yes" · MiddleSeatBlocked "No" · HealthCert "Yes"
    그래서
    언제 바뀌었는지는 우리가 따로 감시해야 함(③ 정책 변경 이력)
  • 가격 투명성 · 운임 규정 원문 API우리 PCC가 있어야 해서 못 받음 (받으면 적립 마일·기간별 수수료)
    무엇
    문서에 없던 API. 10/13 시험했지만 실제 응답은 못 받음
    예시
    GetPriceTransparency: "필수 입력 항목 PCC가 없습니다."
    여정 입력은 "^" 구분 20칸 이상인데 형식 문서 없음
    GetAirPricing · GetFareRule: 위 응답의 키가 있어야 함
    받으면
    적립 마일·적립률 · 출발 전 기간별 취소·변경 수수료 · 구간별 규정
    열려면
    우리 PCC(또는 써도 되는 PCC) + 여정 형식 문서 → 트래블포트 확인 필요
  • 빈 항목항공사 정보 · 좌석 배치도
    무엇
    필드나 API는 있는데 값이 비어서 옴
    예시
    AirlineInfo · AirlineInfoLink · AirlineInfoImage: "" (문서상 준비 중)
    SeatArrangement: {"ColDef": ""}
    BrandedFare: "조건에 맞는 Family 결과가 없습니다."
  • 이용 조건호출 한도·과금·사진 사용 범위 미확인
    무엇
    얼마나 불러도 되는지, 돈이 드는지, 사진을 화면에 써도 되는지 아직 모름
    참고
    지금은 개발 서버만 조회 · 운영 서버 호출은 Aggregator 몫
+

선제적으로 모아야 할 것

AirPlus에 없거나 "있음"만 오는 것

  • 회원·동맹 등급별 추가 수하물
    왜
    AirPlus 요청에 회원 등급을 넣을 칸이 없음
    예시
    대한항공 모닝캄 +1개, 스카이팀 엘리트 플러스 +1개 같은 혜택
    방법
    항공사 공홈 회원 혜택 페이지
  • 반려동물허용 조건·요금
    왜
    응답에 항목 없음
    예시
    기내 동반 가능 여부·무게 한도·케이지 크기·요금·금지 노선
    방법
    공홈 + URL 변경 감지
  • 특수수하물스포츠 장비·악기·유모차·휠체어
    왜
    응답에 항목 없음
    예시
    골프백·자전거·서핑보드, 악기 좌석 구매, 유모차·휠체어 무료 여부
    방법
    공홈
  • 제한·위험물배터리 등
    왜
    응답에 항목 없음
    예시
    보조배터리 용량 기준(Wh), 기내·위탁 반입 가능 여부
    방법
    공홈
  • 수하물 사고·보상 규정
    왜
    응답에 항목 없음
    예시
    지연·파손·분실 신고 기한, 보상 한도
    방법
    공홈
  • 환승 수하물 규정연결 수속·셀프 환승
    왜
    환승 조회는 허용량만 주고 규정은 없음
    예시
    최종 목적지까지 연결 수속되는지, 다른 항공사 연결 시 기준
    방법
    공홈
  • 특수운임 조건학생·선원·근로자·군인
    왜
    요청해도 대부분 성인 운임으로 대체됨(②)
    예시
    선원·학생 운임의 추가 허용량(예: 40kg)과 자격 요건(증빙 서류 등)
    방법
    공홈 + GDS 실측
  • 노선 범위 정의어느 노선에 어떤 규정이 적용되는지
    왜
    AirPlus는 조회 1건의 답만 줌(②)
    예시
    "미주 노선", "아시아 역내" 같은 범위가 어느 공항까지인지
    방법
    공홈
  • 초과요금 전체무게·크기 초과 · 사전 구매 할인
    왜
